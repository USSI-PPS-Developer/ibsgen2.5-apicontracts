# API Contract — Dropping Kas

> Modul: **Pengelolaan Kas / Dropping Kas**
>
> Generated on **2025-10-27** by *PT USSI Pinbuk Prima Software*

---

## 🎯 Tujuan
Fitur ini digunakan untuk melakukan dropping kas dari Kas Besar (Kredit) ke Kas Teller (Debet) secara otomatis.

---

## 🔐 Autentikasi
Semua endpoint menggunakan header:
```
Authorization: Bearer <token>
X-Request-Id: <uuid>
```
